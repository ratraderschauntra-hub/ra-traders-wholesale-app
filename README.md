# RA Traders Wholesale App

A modern wholesale ordering dashboard and catalog app for RA Traders.

## Features
- Product catalog with wholesale pricing
- Retailer-friendly pricing tiers
- Order overview and dispatch dashboard
- Inventory health tracking
- Mobile-friendly and clean B2B design

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Project Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
